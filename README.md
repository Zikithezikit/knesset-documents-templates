# תבניות מסמכי הכנסת – הכנסת ה-26

אוסף תבניות (Word) למסמכים פרלמנטריים של חבר כנסת, יחד עם מסמכים לדוגמה וקובץ **סקיל** שמלמד את Claude לעבוד כעוזר פרלמנטרי: לבחור את המסמך הנכון, למלא אותו מהעובדות שאתם נותנים לו ולהחזיר טיוטה מוכנה לחתימה.

> ⚠️ Claude מכין **טיוטות בלבד**. הוא לא מגיש, לא שולח ולא חותם בשמכם. כל טיוטה צריכה בדיקה שלכם, ובמסמכים תקציביים, חוקי יסוד ותקנון הכנסת גם בדיקה של היועץ המשפטי.

## מה יש בריפו

```text
.
├── תבניות מסמכי הכנסת – הכנסת ה-26/   41 תבניות + אינדקס ומדריך
│   ├── 00 אינדקס ומדריך לתבניות.docx
│   ├── 01 חקיקה והצעות חוק/
│   ├── 02 מליאה ופיקוח פרלמנטרי/
│   ├── 03 ועדות הכנסת/
│   └── 04 נשיאות, סיעות ומכתבים/
├── לדוגמה/                              32 מסמכים אמיתיים שנוצקו לתבנית
│   └── (אותן ארבע תיקיות)
└── סקיל – עוזר לחבר כנסת/
    └── SKILL.md                         ההוראות ל-Claude
```

- **תבניות** – מסמכי Word בעברית (RTL) עם שדות מסומנים באפור. בסוף כל תבנית יש עמוד "הנחיות למילוי".
- **לדוגמה** – מסמכים אמיתיים שפורסמו בכנסת. משמשים כמודל לניסוח, מבנה ורמת פירוט. לא מעתיקים מהם תוכן.
- **סקיל** – כללי העבודה, טבלת "איזה מסמך לאיזו מטרה" ותהליך המילוי.

לא לכל מסמך יש דוגמה. למשל אין דוגמה ל-02-06, 02-07, 02-10, 02-11, 02-13, 02-17 ו-04-01.

## שימוש עם Claude

### אפשרות א׳ – Claude Code (מומלץ לעבודה על קבצים)

1. שכפלו את הריפו:

   ```bash
   git clone https://github.com/Zikithezikit/knesset-documents-templates.git
   cd knesset-documents-templates
   ```

2. התקינו את הסקיל, כך ש-Claude יטען אותו אוטומטית:

   ```bash
   mkdir -p ~/.claude/skills/knesset-mk-assistant
   cp "סקיל – עוזר לחבר כנסת/SKILL.md" ~/.claude/skills/knesset-mk-assistant/SKILL.md
   ```

3. הפעילו `claude` מתוך תיקיית הריפו וכתבו בקשה במילים שלכם, למשל:

   ```text
   אני ח"כ מסיעת ___. אני רוצה להגיש הצעת חוק שמתקנת את חוק ___ כך ש___.
   תכין לי את הטיוטה.
   ```

   ```text
   תכין שאילתה דחופה לשר הבריאות בנושא ___. העובדות והמקורות: ___
   ```

**חשוב:** הסקיל כתוב לעבודה מול **Google Drive**: הוא מצביע על תיקיות Drive, מעתיק תבנית ומשלים אותה כ-Google Doc בתיקיית `טיוטות`. כדי שזה יעבוד כמו שהוא צריך:

- לחבר ל-Claude את מחבר Google Drive/Docs.
- להעלות את התבניות ל-Drive שלכם ולעדכן ב-`SKILL.md` את מזהי התיקיות (`1Pj91pst…` לתבניות ו-`1mtSkBoz…` לדוגמאות).

אם אתם רוצים לעבוד **ללא Drive**, בקשו מ-Claude במפורש לעבוד על קבצי ה-`.docx` שבריפו: "העתק את התבנית לתיקיית `טיוטות` ומלא אותה כקובץ Word". הוא ישתמש בתבנית ובדוגמה המתאימה, והעתק התבנית יישמר בתיקייה נפרדת בלי לגעת במקור.

### אפשרות ב׳ – פרויקט ב-claude.ai

1. צרו פרויקט חדש והעלו אליו את `SKILL.md`, את אינדקס התבניות ואת התבניות והדוגמאות שרלוונטיות אליכם.
2. הדביקו ב-Project instructions שורה כמו: "פעל לפי הקובץ SKILL.md כעוזר פרלמנטרי של חבר כנסת".
3. בקשו מסמך בשיחה. Claude יחזיר את הנוסח המלא לשיחה, ותעתיקו אותו לתבנית ב-Word.

## איך נראית עבודה טיפוסית

1. **אתם** מספרים מה רוצים להשיג: שם החבר/ה, הסיעה, המטרה במשפט אחד, העובדות והמקורות, מי עוד חותם ומה המועד.
2. **Claude** בוחר מסמך (או חבילה: הצעת חוק פרטית היא 01-01 או 01-02 **וגם** טופס חתימות 01-05).
3. הוא בודק מול תקנון הכנסת ומקורות רשמיים מה המצב העדכני, מעתיק את התבנית וממלא רק את השדות האפורים.
4. הוא מחזיר קישור לטיוטה ורשימה קצרה של מה שנשאר לכם: חתימות, חותמים נוספים, עובדות חסרות ופריטים לבדיקה משפטית.

## כללי היסוד שהסקיל אוכף

- **טיוטה בלבד.** אין הגשה, שליחה או חתימה. תיבות החתימה נשארות ריקות.
- **אין המצאות.** שם, תאריך, מספר הצעה, נתון או ציטוט שלא סיפקתם ולא אומתו נשארים כשדה ריק ונרשמים ברשימה שמוחזרת לכם.
- **קול רשמי.** עברית פורמלית, בלי הערות לקורא ובלי "קול של AI" בתוך המסמך. כל הערה אליכם נמצאת בתגובה בשיחה.
- **תבניות ודוגמאות לא נערכות.** תמיד מעתיקים קודם.
- **פרטיות.** תעודת זהות, טלפון וכתובת נכנסים למסמך רק אם נתתם אותם והטופס דורש.
- **לא עורך דין.** Claude מסמן מסמכים שמצריכים בדיקה של היועץ המשפטי של הכנסת או של הוועדה.
